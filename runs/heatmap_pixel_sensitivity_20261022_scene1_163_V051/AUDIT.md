# 热图与 foveation 像素敏感性诊断

同一真实关键帧构造三种输入：180 度翻转的真实 gaze 热图、零热图、原始真实热图。翻转仅用于反事实检查；未输入目标标签、坐标答案或 GT。

- 热图热点象限：3/3 正确。
- Foveation 可见焦点：0/3 张被报告。
- 视觉编码器实际消费张量校验：通过。
- 热图中心坐标有 2 张以像素值输出，不符合归一化坐标格式；象限正确不能替代精确定位。
- Foveation 响应是有效 JSON 数组，但 backend 契约要求 JSON 对象；原始内容和失败记录均保留。诊断汇总时将数组包装为对象，解析状态为 `valid_json_array_backend_schema_mismatch_normalized_for_diagnostic`。

该测试证明线索图的像素变化是否被视觉读取，不检验目标指代精度，也不代表系统级性能收益。
